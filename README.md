# INT8-AI-Accelerator

A SystemVerilog-based RTL project focused on designing and verifying an INT8 Multiply-Accumulate (MAC) accelerator.

Current implementation includes:

* Sequential MAC unit
* 2x2 MAC array
* RTL simulation and verification
* Waveform analysis

## Tools Used

* SystemVerilog
* Xilinx Vivado
* GitHub

## Future Work

* Scalable MAC arrays
* Assertion-based verification
* Functional coverage
* UVM-based verification
