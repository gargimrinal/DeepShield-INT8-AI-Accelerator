
This folder contains the initial and experimental implementations of the INT8 MAC array architecture.

These designs were created during the early RTL development phase to:

* validate MAC functionality
* test architectural approaches
* compare dataflow strategies
* debug array behavior before optimization

Contents may include:

* non-row/column implementations
* prototype MAC array connections
* initial sequential designs
* experimental RTL versions

These files are preserved for:

* design evolution tracking
* architectural comparison
* debugging reference
* learning and documentation purposes

Note:
The designs in this folder are not considered final optimized implementations. Stable and validated RTL is maintained in the main `rtl/` directory.
